# AI-Image-Detective

Now supports:
- Image to detailed description (`/api/analyze`)
- PDF to text extraction (`/api/extract-pdf`)

## Python dependencies

Install these in your Python virtual environment:

```bash
pip install -r requirements.txt
```

## Node dependencies

```bash
npm install
```

## Run backend

From project root:

```bash
npm run server
```

If your Python executable is not at the default `venv` path, set:

```bash
PYTHON_PATH=/full/path/to/python node server.js
```

## Run frontend

```bash
npm run dev
```
